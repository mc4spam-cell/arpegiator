Help dialog

Modal dialog opened from the header's « i » button. It recaps how to operate the sliders, details the role of the three T / R / G flags, and shows the author and the last publication date.

Slider usageDrag vertically in a slider to set a value. Double-click to reset.
T flag — TieThe previous step's note is sustained through this step, with no new attack (like a tie in music notation).
R flag — RandomOn each pass, the engine picks a random note from the current chord instead of following the arpeggio order.
G flag — GlidePitch slides continuously up or down from the previous step's note (portamento / slide).
Playback reminderDuring playback, each chord lasts one bar, and the grid loops.
