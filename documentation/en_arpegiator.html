Main screen

Arpegiator is a single-page step arpeggiator: you define a chord grid, configure each step (pitch, octave, length, and three T/R/G flags), and press play. The current chord is arpeggiated using the chosen order (up, down, random, …); the grid loops over a cycle of bars, one chord per bar. Language selector (6 languages: FR / EN / ES / DE / ZH / RU) and built-in help in the header.

Interface overview

Header« Arpegiator » title, tagline subtitle, round Help button (i), and round language selector (flag).
Transport sectionPanel grouping every playback setting: BPM, Meter (3/4, 4/4, 5/8, 7/8), Steps per bar (1 to 48), Rate (1/4 to 1/32 including triplets), arpeggio Order, Octaves, and Swing.
Chord gridOne compact row per chord: root, quality (maj, min, maj7, …), octave, note preview. A round + button at the right inserts a new chord after the row. From the 2nd row on, a round − button removes the row. The chord currently playing is outlined with the accent color.
Step gridSeven stacked lanes, one per parameter: STEP (on/off button per step), PITCH, OCTAVE, LENGTH (vertical sliders with a « random » die to shuffle the whole row), then TIE, RANDOM NOTE, and GLIDE (one lane per flag, one colored button per step). Drag vertically in a slider to set a value; double-click resets to zero. ‹ › arrows appear when the grid overflows horizontally.
Fixed bottom action barAlways visible on every screen size: Play/Stop button (label follows state) and Export MIDI button.
