Main screen

Arpegiator is a single-page step arpeggiator: you define a chord grid, configure the step lanes (pitch, octave, duration, T/R/G flags), and press play. The current chord is arpeggiated using the chosen order (up, down, random, …); the grid loops over a cycle of bars, one chord per bar.

Interface overview

HeaderTitle, subtitle, Help button (i), and language selector (flag).
Transport sectionPanel grouping all playback settings: BPM, Meter (3/4, 4/4, 5/8, 7/8), Steps per bar (1 to 48), Rate (1/4 to 1/32, including triplets), arpeggio Order, Octaves, and Swing.
Chord gridEach row defines a chord by its root, quality (maj, min, maj7, …) and octave. ✕ button removes the chord; « + Add chord » extends the grid. The chord currently playing is outlined with the accent color.
Step gridOne lane per parameter: on/off bar, pitch, octave, length, flags T (tie), R (random from chord), G (glide). Each column is one step. Drag vertically on a slider to set a value; double-click resets to zero. The « random » die randomizes the whole row. ‹ › arrows appear when the grid overflows horizontally.
Fixed bottom action barPlay/Stop button (label follows state) and Export MIDI button. Always visible, on all screen sizes.
